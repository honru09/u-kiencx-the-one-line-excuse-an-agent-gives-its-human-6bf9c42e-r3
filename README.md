The bounty is a competition with a $5 prize pool: the prize is paid only if this entry wins. There is no guaranteed income from entering.

## How it works

`main.py` (Python 3, standard library only) writes one excuse line to `/output/entry.txt`, validates it is 1–160 characters and a single line, then reads it back to verify.

```sh
python3 main.py
```
